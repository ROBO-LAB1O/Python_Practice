# Python_Practice

Small projects I built while learning Python: OOP, NumPy, and more.

## Projects

### ATMproject.1
An ATM simulator built with Python OOP.

- PIN verification
- Check balance, deposit, withdraw
- Change PIN (must be 4 digits)
- Account locks after 3 wrong PIN attempts
- Private attributes (encapsulation)

**Run it:** open the folder and run `python main.py`

**Files:**
- `atm.py`: the ATM class (data and rules)
- `main.py`: the menu that talks to the user
